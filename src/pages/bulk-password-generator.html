What happens to these passwords

  • Made on your device. Your browser's secure random generator creates every one. No server is involved.
  • Never sent anywhere. Generating, copying, and downloading make no network request.
  • Not saved. Your settings are remembered on this device. The passwords and labels are not, and they're gone when you close the tab.
  • Spreadsheet-safe. No password starts with = + - or @, so Excel and Google Sheets can't treat one as a formula.

Your passwords

A CSV file is plain text on your disk. Anyone who opens it can read every password. Import it into your password manager or RMM, then delete the file and empty your trash.

#LabelPasswordCopy

Built for setting up many accounts

One per user

Paste a list of usernames, one per line, and each gets its own password. The CSV has a Label column and a Password column, ready to import. Every password in a batch is different.

Safe to open in Excel

A cell that starts with = + - or @ can run as a formula. Passwords here never start with one, and any label that does gets a leading apostrophe so it stays plain text.

Delete the file after

The download is made in your browser, but once it's saved it's an ordinary unencrypted file. Import it, then delete it. Better still, have users change their password at first sign-in.
